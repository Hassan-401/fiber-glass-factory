# موقع سوق مصرية فيبر جلاس

موقع تعريفي لمصنع **سوق مصرية فيبر جلاس**، مع لوحة تحكم كاملة.
مبني على **Cloudflare Workers + D1**، والواجهة HTML/CSS/JS خالص بدون أي مكتبات.

| | الرابط |
|---|---|
| الموقع | https://souq-masreya-fiberglass.go-sharm.workers.dev |
| لوحة التحكم | https://souq-masreya-fiberglass.go-sharm.workers.dev/admin |

---

## اللغات

الموقع عربي وإنجليزي. زر التبديل (ع / EN) في الشريط العلوي، والاختيار محفوظ للزائر.
تقدر كمان تفتح أي صفحة بلغة معيّنة بإضافة `?lang=en` أو `?lang=ar` للرابط.

- **محتوى المصنع** (أسماء الأقسام والمنتجات والنبذة والأسئلة الشائعة) له نسخة
  إنجليزية في قاعدة البيانات، وتتعدّل من لوحة التحكم — أي حقل إنجليزي فاضي
  بيرجع للعربي تلقائياً.
- **نصوص الواجهة** (القوائم والأزرار والعناوين) في `public/assets/js/i18n.js`.
  لإضافة ترجمة جديدة ضيف السطر في كائن `UI` هناك.
- الاتجاه (RTL/LTR) بيتبدّل تلقائياً مع اللغة.

## المحتوى

- **18 قسم إنتاج** و **151 منتج** بـ **163 صورة** — كلها حقيقية من المصنع (مصدرها مجلد `داتا/`).
- الصور اللي لنفس المنتج متجمّعة في **كاروسيل** داخل صفحة المنتج بدل ما تكون منتجات منفصلة.
- 4 أقسام لسه من غير صور، بتظهر بخامة مؤقتة بلون الشعار مع دعوة للسؤال على واتساب.

## لوحة التحكم

ادخل على `/admin`. بيانات الدخول الأولى في ملف `ADMIN-PASSWORD.txt` المحلي
(مش مرفوع على GitHub). **غيّر كلمة السر من تبويب «حسابي» بعد أول دخول.**

| التبويب | بيعمل إيه |
|---|---|
| لوحة المعلومات | عدد الأقسام والمنتجات وزوار الموقع |
| الأقسام | إضافة/تعديل/حذف، إخفاء، أيقونة، ترتيب بالسحب |
| المنتجات | إضافة/تعديل/حذف، صور متعددة بترتيب، «مختار»، إخفاء، بحث وفلترة، **دمج منتجات** في منتج واحد |
| الصور | رفع صور وحذفها (مخزّنة في قاعدة البيانات) |
| بيانات الموقع | التليفون، الواتساب، العنوان، المواعيد، الخريطة، السوشيال ميديا |
| محتوى الصفحات | النبذة، «لماذا نحن»، خطوات العمل، الأسئلة الشائعة |
| حسابي | تغيير كلمة السر واسم المستخدم |

أي تعديل بيظهر على الموقع فوراً — من غير إعادة رفع.

### دمج صور منتج واحد
في تبويب المنتجات، علّم على المنتجات اللي صورها لنفس المنتج ← **«دمج المحدد في منتج واحد»**.
الصور كلها بتتجمّع في المنتج الأول وتظهر ككاروسيل، والباقي بيتحذف.

### الأمان
- كلمة السر متخزّنة PBKDF2-SHA256 بـ 100,000 دورة وملح عشوائي.
- الجلسة كوكي موقّع HMAC، HttpOnly + Secure + SameSite=Strict، صالح 14 يوم.
- تغيير كلمة السر بيبطّل كل الجلسات على الأجهزة التانية.
- الطلبات المغيِّرة بتتحقق من الـ Origin (حماية CSRF).

## عدّاد الزوار

في الفوتر عدّادين: **إجمالي الزوار** و **زوار الشهر الحالي** (بيبدأ من الصفر أول كل شهر).
العدّ في قاعدة بيانات الموقع نفسها (مش خدمة خارجية)، والزيارة بتتحسب مرة واحدة
لكل جلسة تصفّح فالتنقل بين الصفحات مش بيزوّد الرقم.

---

## الطلب عبر واتساب

- زر عائم في كل الصفحات.
- زر «اطلب الآن» على كل منتج — بيفتح محادثة برسالة جاهزة فيها اسم المنتج وكوده وقسمه ورابطه.
- نموذج التواصل بيبني رسالة منظمة من بيانات الفورم.

## الهيكل

```
.
├── wrangler.jsonc          ← إعدادات Cloudflare
├── schema.sql              ← جداول قاعدة البيانات
├── worker/index.js         ← الـ API والتوجيه والمصادقة
├── public/                 ← كل اللي بيتقدّم للمتصفح
│   ├── index.html · categories.html · products.html
│   ├── product.html · about.html · contact.html · 404.html
│   ├── admin/              ← لوحة التحكم
│   └── assets/
│       ├── css/style.css
│       ├── js/  config.js · data.js · icons.js · main.js
│       └── img/ logo.png · products/<القسم>/
├── tools/                  ← أدوات محلية (مش جزء من الموقع)
└── داتا/                    ← المصدر الأصلي (صور + ملفات Word)
```

**من فين بتيجي البيانات؟** الموقع بيقرأ من `/api/site` (قاعدة البيانات).
ملفات `config.js` و `data.js` نسخة احتياطية مدمجة بتشتغل لو الـ API مش متاح.

## التطوير والنشر

```bash
npm install -g wrangler        # مرة واحدة
wrangler login                 # مرة واحدة
```

### تشغيل محلي
```bash
wrangler d1 execute souq-masreya-fiberglass --local --file=./schema.sql
node tools/seed-db.js --password "كلمة-سر-للتجربة"
wrangler d1 execute souq-masreya-fiberglass --local --file=./seed.sql
wrangler dev
```

### النشر
```bash
wrangler deploy
```

## إضافة صور من المصدر الأصلي

لو ضفت صور جديدة في مجلد `داتا/` وعايز تعيد بناء الكتالوج من الأول:

```bash
node tools/build-data.js        # ينسخ الصور ويولّد data.js
node tools/to-webp.js           # يحوّلها WebP ويصغّرها (افتح localhost:8796)
```

> للتعديلات اليومية (إضافة منتج أو تغيير صورة) استخدم **لوحة التحكم** —
> الأدوات دي للبناء الأولي من المجلد المصدر بس، وتشغيلها بيمسح صور `public` ويعيد نسخها.

### تجميع صور المنتج الواحد
`tools/groups.json` فيه قائمة الصور اللي لنفس المنتج (مراجَعة يدوياً).
`tools/hash-images.js` + `tools/cluster-images.js` بيقترحوا تجميعات بالمقارنة البصرية.

## الصور

كل صور الموقع بصيغة **WebP** (أصغر 40–60% من JPEG بنفس الجودة).

- الصور الحالية اتحوّلت بـ `tools/to-webp.js` — بيصغّر لأقصى عرض 1600px
  بجودة 82% وبيحافظ على الشفافية لو موجودة، وبيحدّث `data.js` وبيولّد
  `webp.sql` لتحديث قاعدة البيانات.
- **أي صورة بترفعها من لوحة التحكم بتتحوّل WebP في المتصفح قبل ما تتبعت** —
  نفس التصغير (1600px) وجودة 85%. لو المتصفح مش داعم WebP بترفع زي ما هي.
- `logo.png` فاضل موجود لأيقونة المتصفح بس؛ الشعار المعروض في الصفحات `logo.webp`.
