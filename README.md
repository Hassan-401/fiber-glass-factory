# موقع مصنع الشروق للفايبر جلاس — نسخة تجريبية

موقع تعريفي كامل لمصنع فايبر جلاس، مبني بـ **HTML + CSS + JavaScript** فقط،
بدون أي مكتبات أو أطر عمل خارجية وبدون أي خطوة بناء (build step).

> ⚠️ **كل البيانات في هذه النسخة وهمية** (اسم المصنع، العناوين، أرقام الهواتف،
> البريد الإلكتروني، روابط السوشيال ميديا، آراء العملاء). استبدلها بالبيانات الحقيقية قبل النشر.

---

## 🟢 الطلب عبر واتساب

الطلب يتم بالكامل عبر واتساب — لا يوجد سلة شراء ولا خادم ولا قاعدة بيانات:

* **زر عائم** في كل صفحة.
* **زر «اطلب الآن»** على كل بطاقة منتج.
* **زر «اطلب هذا المنتج»** في صفحة تفاصيل المنتج — يرسل رسالة جاهزة تحتوي على
  اسم المنتج + كوده + القسم + رابط الصفحة.
* **نموذج التواصل** في `contact.html` يجمع بيانات العميل ويحوّلها لرسالة واتساب منسّقة
  (أو رسالة بريد إلكتروني كبديل).

### تغيير رقم الواتساب

في [`assets/js/data.js`](assets/js/data.js) عدّل السطر:

```js
whatsapp: "201001234567",   // بصيغة دولية بدون + وبدون مسافات
```

## ✏️ كيف تعدّل المحتوى

كل شيء في ملف واحد: **`assets/js/data.js`**

| ما تريد تعديله | أين |
|---|---|
| اسم المصنع، العنوان، الهواتف، البريد، مواعيد العمل | كائن `SITE` |
| روابط السوشيال ميديا | `SITE.social` |
| الإحصائيات (سنوات الخبرة، عدد العملاء…) | `SITE.stats` |
| مميزات «لماذا نحن» وخطوات العمل والآراء والأسئلة الشائعة | `SITE.why` / `SITE.steps` / `SITE.testimonials` / `SITE.faq` |
| الأقسام | مصفوفة `CATEGORIES` |
| المنتجات | مصفوفة `PRODUCTS` |

### إضافة منتج جديد

```js
{ id:"tanks-11", cat:"tanks", name:"اسم المنتج", tag:"جديد", featured:true,
  desc:"وصف مختصر يظهر في البطاقة وصفحة التفاصيل.",
  specs:{"السعة":"…","القطر":"…","الارتفاع":"…","الخامة":"…"},
  feat:["ميزة 1","ميزة 2","ميزة 3","ميزة 4"] }
```

ثم ضع صورة المنتج في `assets/img/products/tanks-11.jpg` — الصورة تُربط تلقائياً من الـ `id`.

* `featured: true` → يظهر ضمن «منتجات مختارة» في الصفحة الرئيسية.
* `tag: "…"` → شارة ذهبية أعلى صورة المنتج.

### إضافة قسم جديد

أضف عنصراً في `CATEGORIES` بـ `id` و `name` و `short` و `desc` و `icon`
(الأيقونة من الأسماء الموجودة في [`assets/js/icons.js`](assets/js/icons.js))،
وضع صورة الغلاف في `assets/img/categories/<id>.jpg`.

## 🖥️ التشغيل

افتح `index.html` مباشرة في المتصفح — يعمل بدون سيرفر.

للتشغيل عبر سيرفر محلي (أفضل للاختبار):

```bash
npx serve .
```

للنشر: ارفع كل الملفات كما هي على أي استضافة ثابتة
(Netlify / Vercel / GitHub Pages / أي استضافة عادية) — لا تحتاج PHP ولا قاعدة بيانات.

## ✅ ما هو منفَّذ

- تصميم عربي **RTL** بالكامل ومتجاوب مع الموبايل والتابلت والديسكتوب.
- هيرو مطابق للتصميم المرجعي على الشاشات الكبيرة (بمناطق ضغط تفتح الأقسام)،
  ونسخة مبنية بالكود على الموبايل.
- بحث فوري + فلترة بالأقسام + ترتيب، مع مزامنة الفلاتر مع رابط الصفحة.
- صفحة منتج بمواصفات ومميزات ومنتجات ذات صلة وزر مشاركة.
- نموذج تواصل بتحقق من المدخلات → رسالة واتساب أو بريد.
- أكورديون للأسئلة الشائعة، عدادات متحركة، ظهور تدريجي عند التمرير،
  زر عودة لأعلى، قائمة جانبية للموبايل.
- يحترم `prefers-reduced-motion`، وروابط ووصف بديل للصور.

## 📌 قبل النشر

1. استبدل البيانات الوهمية في `data.js` ببيانات المصنع الحقيقية.
2. **استبدل الصور بصور منتجاتك الحقيقية** — الصور الحالية صور توضيحية
   مأخوذة من ويكيميديا كومنز لأغراض العرض فقط، وكل صورة لها ترخيصها الخاص
   الذي قد يتطلب ذكر المصدر.
3. عدّل رابط خريطة جوجل في `SITE.mapEmbed` ليشير لموقع المصنع الفعلي.
4. أضف أيقونة الموقع (favicon) وشعار المصنع بدل الشعار المؤقت.
