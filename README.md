# موقع سوق مصرية فيبر جلاس

موقع تعريفي لمصنع **سوق مصرية فيبر جلاس** — مبني بـ HTML و CSS و JavaScript فقط،
بدون أي مكتبات خارجية أو خطوة بناء. الطلب كله بيتم عبر واتساب.

![الصفحة الرئيسية](assets/img/logo.png)

---

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو شغّل سيرفر محلي بسيط:

```bash
npx serve .
```

---

## الصفحات

| الصفحة | الملف | الوصف |
|---|---|---|
| الرئيسية | `index.html` | الهيرو، الأقسام، منتجات مختارة، معرض صور |
| الأقسام | `categories.html` | كل أقسام المصنع |
| المنتجات | `products.html` | بحث وفلترة وترتيب لكل المنتجات |
| تفاصيل منتج | `product.html?id=…` | بيانات المنتج وزر الطلب |
| عن المصنع | `about.html` | نبذة والقطاعات اللي بنخدمها |
| تواصل معنا | `contact.html` | بيانات التواصل، خريطة، نموذج طلب، أسئلة شائعة |

## المحتوى: من فين بيجي؟

كل المنتجات والصور **حقيقية من المصنع**، مصدرها مجلد `داتا/`.

- **18 قسم إنتاج**
- **163 منتج** معروض بالصور
- 4 أقسام لسه من غير صور (كفرات أجهزة طبية، مراكب ولنشات، مراوح شفط هواء،
  مواسير وخزانات) — بتظهر بخامة مؤقتة بلون الشعار ومكتوب عليها «الصور قريباً».

### إضافة صور أو أقسام جديدة

1. حط الصور في المجلد المناسب داخل `داتا/`
   (أو اعمل مجلد جديد وضيفه لمصفوفة `CATEGORIES` في `tools/build-data.js`).
2. شغّل:

```bash
node tools/build-data.js
```

ده بينسخ الصور لـ `assets/img/products/<اسم القسم>/` وبيولّد `assets/js/data.js`.

3. بعدها شغّل ضاغط الصور (بيصغّر أي صورة أكبر من 300KB لعرض أقصى 1600px):

```bash
node tools/optimize-images.js
```

وافتح `http://localhost:8792/` وسيب الصفحة تخلّص لوحدها.

> **مهم:** `assets/js/data.js` ملف **مولَّد تلقائياً** — متعدّلوش بإيدك،
> أي تعديل هيتمسح أول ما تشغّل `build-data.js` تاني.

## تعديل بيانات المصنع

كل بيانات التواصل والسوشيال ميديا في ملف واحد: **`assets/js/config.js`**

```js
whatsapp: '201000000000',   // رقم الواتساب بصيغة دولية بدون +
phone1:   '0100 000 0000',
email:    'info@example.com',
address:  '…',
social:   [ { key: 'facebook', name: 'فيسبوك', url: '…' }, … ]
```

### ⚠️ الوضع الحالي: بيانات التواصل مؤقتة

الأرقام والعناوين وروابط السوشيال ميديا الموجودة دلوقتي **وهمية للعرض فقط**.
لما تحط البيانات الحقيقية:

1. عدّل الحقول في `assets/js/config.js`
2. غيّر `demo: true` إلى `demo: false` — ده بيخفي تنبيه «نسخة تجريبية» من الفوتر

## عدّاد الزوار

في الفوتر عدّادين:

- **إجمالي زوار الموقع** منذ إطلاقه
- **زوار الشهر الحالي** (بيبدأ من الصفر أول كل شهر تلقائياً)

بيشتغلوا عبر خدمة [abacus](https://abacus.jasoncameron.dev) المجانية — عدّاد مجهول
تماماً، مفيش أي بيانات شخصية بتتبعت، مجرد زيادة رقم.

- الزيارة بتتحسب **مرة واحدة لكل جلسة تصفّح** (عن طريق `sessionStorage`)،
  فالتنقل بين صفحات الموقع مش بيزوّد العداد.
- لو الخدمة مش متاحة، بيظهر «—» بدل الرقم والموقع بيكمل شغل عادي.
- لتصفير العدّاد: غيّر `counter.ns` في `config.js` لأي اسم جديد.

## الطلب عبر واتساب

- زر عائم في كل الصفحات
- زر «اطلب الآن» على كل منتج — بيفتح محادثة برسالة جاهزة فيها
  **اسم المنتج + كوده + قسمه + رابط صفحته**
- نموذج التواصل بيبني رسالة منظمة من بيانات الفورم ويبعتها على واتساب

## هيكل المشروع

```
.
├── index.html · categories.html · products.html
├── product.html · about.html · contact.html
├── assets/
│   ├── css/style.css          ← كل التنسيقات (ألوانها مأخوذة من الشعار)
│   ├── js/
│   │   ├── config.js          ← بيانات المصنع ← عدّل هنا
│   │   ├── data.js            ← مولَّد تلقائياً ← متعدّلوش
│   │   ├── icons.js           ← أيقونات SVG مضمّنة
│   │   └── main.js            ← الهيدر والفوتر والتفاعلات والعدّاد
│   └── img/
│       ├── logo.png
│       └── products/<القسم>/  ← صور المنتجات
├── tools/
│   ├── build-data.js          ← يبني data.js وينسخ الصور من «داتا»
│   └── optimize-images.js     ← يضغط الصور الكبيرة
└── داتا/                       ← المصدر الأصلي (صور + ملفات Word)
```

## ملاحظات

- الموقع عربي بالكامل (RTL) ومتجاوب مع كل المقاسات.
- خط Cairo من Google Fonts — لو عايزه يشتغل أوفلاين نزّله محلياً.
- بيحترم `prefers-reduced-motion` لمن يفضّل تقليل الحركة.
